# nelko-p21-cli

A macOS-first CLI for one nearby Nelko P21 Bluetooth label printer.

Production design is tracked in the [current Wayfinder map](https://github.com/KalebCole/nelko-p21-cli/issues/15). The default branch contains durable evidence and planning material only; disposable hardware probes are preserved on the `archive/p21-evidence-2026-09-14` branch.
